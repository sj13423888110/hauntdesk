# Product: HauntDesk — AI Agent Control Room

HauntDesk is a Halloween-themed AI agent dashboard built for Kiroween 2026.
It presents a playful but genuinely usable "control room" metaphor for
working with a team of AI agents.

## Core concept

- The user is the operator of a haunted control room on the night shift.
- A roster of themed AI agents (Ghost Coder, Pumpkin Planner, Vampire
  Reviewer, Witch Researcher, Skeleton QA, Zombie DevOps) each has a role
  and a specialty skill.
- The user dispatches tasks; agents pick them up, stream a live log of
  plausible role-specific work steps, and complete them with a result
  summary.
- Progress is gamified with a "candy meter" and a haunted house whose
  windows light up as tasks complete.

## Product principles

- **Playful, not a poster.** Every visual element supports a real
  interaction: dispatching, monitoring, and completing agent work.
- **Zero friction.** No accounts, no keys, no backend, no build step. Open
  the page and the desk is running.
- **Legible at a glance.** An operator should see who is busy, what is
  running, and how the shift is going within two seconds.
- **Halloween is the skin, clarity is the skeleton.** The spooky theme
  (deep purple night, pumpkin orange, slime green, ghost white) never
  compromises readability or status signalling.

## Target user

Hackathon judges and curious visitors evaluating a Kiro-built project in
under three minutes, plus anyone who enjoys agent dashboards.
